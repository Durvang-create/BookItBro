# BookItBro

A simple Movie Booking System developed as a Web Technology project.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- XAMPP

## Features

### User
- User registration and login
- Browse movies
- Select show date and time
- Select seats
- Book tickets
- View bookings
- Update bookings
- Cancel bookings

### Admin
- Admin login
- Add movies
- Edit movie details
- Remove movies
- View customer bookings

## How to Run

1. Install XAMPP.
2. Start Apache and MySQL from XAMPP Control Panel.
3. Copy the project folder into:

C:\xampp\htdocs\

4. Open phpMyAdmin:

http://localhost/phpmyadmin/

5. Import `database.sql`.

6. Open the website:

http://localhost/BookMyShowDurvang/
